# FlowVPN Client (Android) — v0.1.0

Современный, производительный и надёжный VPN-клиент для Android на базе актуального нативного ядра **sing-box (libbox) v1.14.0**. Разработан для обхода цензуры, защиты конфиденциальности, разблокировки зарубежных сервисов и комфортного повседневного использования.

---

## 🌟 Ключевые возможности

### 🚀 Современные протоколы обхода блокировок
- **VLESS Reality & XTLS-Vision**: передовая маскировка TLS-трафика под доверенные веб-сайты.
- **Hysteria 2**: высокоскоростной протокол на базе UDP/QUIC с алгоритмом Brutal Congestion Control и защитой от DPI (`obfs`).
- **Cloudflare WARP & WARP+**:
  - Поддержка протоколов **WireGuard** и **MASQUE (HTTP/2 и HTTP/3)**.
  - **Режим цепочки (VPN ➔ WARP)** в стиле Hiddify: трафик шифруется вашим сервером (VLESS/Hysteria) и направляется в Cloudflare, обеспечивая доступ к сервисам с жесткими геоблокировками (ChatGPT, Netflix, Claude, зарубежные банки).
  - Встроенная генерация ключевой пары RFC 7748 X25519 в чистом Kotlin.
  - Автоматическая регистрация аккаунтов и активация лицензионных ключей **WARP+**.
  - Встроенный сканер чистых Anycast IP-адресов для поиска незаблокированных маршрутов.
- **Outline Shadowsocks**:
  - Поддержка ссылок `ss://` с кастомным префиксом (`prefix=...`) и динамических ссылок `ssconf://`.
  - Встроенный прозрачный локальный мост `OutlineBridge` (SOCKS5) с защитой сокетов через `VpnService.protect`.
- **Классические протоколы**: `Trojan`, `VMess`, `Shadowsocks-2022`, `TUIC`, `SOCKS5`.

### 🛡️ Анти-DPI и сетевые технологии
- **Стек gVisor TUN**: виртуальный высокопроизводительный сетевой стек ядра sing-box 1.14.
- **TLS ClientHello Fragmentation & Record Fragmentation**: разделение заголовков TLS для обхода глубокого анализа пакетов (ТСПУ / DPI).
- **FakeDNS**: виртуальная подсеть `198.18.0.0/15` для устранения задержек разрешения доменов и предотвращения утечек DNS.
- **DNS over HTTPS (DoH)**: предустановленные серверы Cloudflare, Google, AdGuard (блокировка рекламы), Quad9, а также поддержка произвольного DoH URL.
- **Sniffing**: перехват и проверка целевых протоколов (`tls`, `http`, `quic`).

### 🇷🇺 Умная маршрутизация (Smart Routing)
- **Прямой доступ к сервисам РФ (Bypass Russian Traffic)**:
  - Трафик к отечественным ресурсам (Госуслуги, банки, Яндекс, маркетплейсы, домены `.ru`, `.рф`, `.su`, `.by`, `.kz`) идет напрямую без участия VPN, обеспечивая максимальную скорость и отсутствие блокировок по IP.
  - Возможность добавления собственных доменов в список прямого доступа.
- **Раздельное туннелирование (Per-App Split Tunneling)**:
  - Выбор конкретных приложений для работы через VPN (белый список) или мимо VPN (черный список).
- **Аварийный выключатель (Kill Switch)** и блокировка утечек IPv6.

### ⚡ Обход изоляции интернета (OpenFlux)
- Скрытое туннелирование IPv4 TCP трафика через разрешенные отечественные сервисы ([OpenFlux](https://github.com/p1neappleXpress/OpenFlux)) при сценариях отключения внешних каналов связи.
- Поддержка транспортов через **Яндекс Документы** и **MAX Messenger**.

### 📱 Современный дизайн и эргономика
- Полностью нативный интерфейс на **Jetpack Compose (Material Design 3)** с динамическими темами.
- Быстрое управление подключением через **Quick Settings Tile** в системной шторке Android.
- Подробная карточка «О системе» со статусом ядра и версией протоколов.
- Встроенный журнал отладки (логи ядра и приложения) для быстрой диагностики.

## 📱 Системные требования

- **Операционная система**: Android 8.0 (Oreo, API 26) и новее (включая Android 14 и 15).
- **Архитектура процессора**:
  - `arm64-v8a` (основная архитектура практически всех современных смартфонов)
  - `armeabi-v7a` (устаревшие 32-битные устройства)
  - `x86_64` (эмуляторы и планшеты на архитектуре Intel/AMD)

## 🛠️ Сборка проекта из исходников

### Требования:
- JDK 17 (Eclipse Temurin или OpenJDK)
- Android SDK (API 35, Build-Tools 35.0.0)
- Gradle 8.7+ (в комплекте Gradle Wrapper)

### Команда сборки:
```bash
# Linux / macOS:
./gradlew assembleDebug

# Windows PowerShell:
.\gradlew.bat assembleDebug
```

Собранные установочные пакеты APK располагаются по пути:
`app/build/outputs/apk/debug/`
- `app-arm64-v8a-debug.apk` — оптимизированная сборка для 64-битных смартфонов (~115 МБ, включает нативное ядро `libbox.so`).
- `app-universal-debug.apk` — универсальный APK со всеми библиотеками архитектур.

---

## 🚀 Установка и релизы

Готовые сборки APK доступны в разделе **[Releases](https://github.com/nefrozzik/FlowVPN/releases)**.

1. Скачайте актуальный файл `app-arm64-v8a-debug.apk` (или `FlowVPN-v0.1.0-arm64.apk`).
2. Разрешите установку из неизвестных источников в настройках безопасности Android.
3. Откройте приложение, добавьте вашу конфигурацию или подписку и нажмите кнопку подключения.
