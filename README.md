# FlowVPN Client (Android) — v0.0.1-beta

Современный, производительный и надёжный VPN-клиент для Android на базе нативного ядра **sing-box (libbox)**. Разработан для обхода интернет-цензуры, защиты конфиденциальности и комфортного повседневного использования.

---

## 🌟 Ключевые возможности

- **Современные протоколы обхода блокировок**:
  - `VLESS` с технологией `Reality` и `XTLS-Vision`
  - `VMess`, `Trojan`, `Shadowsocks`
  - `Hysteria 2` и `WireGuard`
- **Обход сайтов РФ (Сервисы напрямую)**:
  - Прямой доступ к российским сервисам (Госуслуги, банки, Яндекс, маркетплейсы, домены `.ru`, `.рф`, `.su`, `.by`, `.kz`) без замедлений и блокировок.
  - Просмотр базовых зон и добавление собственных доменов и поддоменов для прямого доступа мимо VPN.
- **Раздельное туннелирование приложений (Per-App Split Tunneling)**:
  - Режим белого списка (VPN только для выбранных приложений).
  - Режим черного списка (VPN для всех, кроме выбранных).
- **Безопасность и защита от утечек**:
  - Поддержка DNS over HTTPS (DoH): Cloudflare, Google, AdGuard (блокировка рекламы), Quad9 или собственный DoH URL.
  - Технология `FakeDNS` и перехват SNI (`Sniffing`) для защиты от цензуры DPI.
  - Аварийная блокировка трафика (`Kill Switch`) при разрыве VPN-соединения.
  - Блокировка утечек IPv6.
- **Интеллектуальный интерфейс**:
  - Автоматическое определение страны и локации по IP-адресу (GeoIP).
  - Быстрый импорт подписок и конфигураций по ссылкам или через буфер обмена.
  - Автоматическое и ручное обновление подписок.
  - Однократный запрос настройки работы без ограничений энергосбережения (Doze Mode).
  - Сбор и экспорт детальных логов приложения и ядра для отладки.

## 📱 Системные требования

- **Android**: версия 8.0 (Oreo, API 26) или новее.
- **Архитектуры процессора**: `arm64-v8a` (основная для 99% современных смартфонов), `armeabi-v7a`, `x86_64`.

---

## 🛠️ Сборка проекта из исходных кодов

### Требования:
- JDK 17
- Android SDK (API 35, Build-Tools 35.0.0)
- Gradle 8.7+ (используется встроенный Gradle Wrapper)

### Сборка Debug APK:
```bash
# Linux / macOS:
./gradlew assembleDebug

# Windows:
.\gradlew.bat assembleDebug
```

Собранные APK-файлы будут созданы в каталоге:
`app/build/outputs/apk/debug/`
- `app-arm64-v8a-debug.apk` — оптимизированная сборка для 64-битных смартфонов (~45 МБ)
- `app-universal-debug.apk` — универсальная сборка под все архитектуры (~314 МБ)
