# Changelog

Все важные изменения проекта FlowVPN Client для Android фиксируются в этом документе.

---

## [0.1.0] — 2026-09-11

Первый крупный стабильный релиз **FlowVPN Client** для Android на базе актуального нативного ядра **sing-box (libbox) v1.14.0**.

### 🚀 Главные нововведения

#### 1. Новое ядро sing-box (libbox) v1.14.0
- Полная миграция на нативную библиотеку `libbox.so` (архитектуры `arm64-v8a`, `armeabi-v7a`, `x86_64`).
- Переход на типизированные DNS-серверы sing-box 1.14 (`local`, `https`, `h3`, `tls`, `udp`, `tcp`) с поддержкой `domain_resolver`.
- Высокопроизводительный виртуальный стек **gVisor TUN** с поддержкой `auto_route` и интеграцией с Android VpnService API 26–35.
- Анти-DPI технологии: **TLS ClientHello Fragmentation**, **Record Fragmentation**, **FakeDNS** (198.18.0.0/15) и активный сниффинг протоколов (`tls`, `http`, `quic`).

#### 2. Cloudflare WARP & WARP+ (Цепочки и автономный режим)
- **Цепочка VPN ➔ WARP (Hiddify Chain Style)**:
  - Трафик шифруется через ваш основной VPN-сервер (VLESS, Hysteria 2, Shadowsocks) и выходит в интернет через Cloudflare WARP.
  - Сайты видят чистый IP-адрес Cloudflare: обход геоблокировок и капч на зарубежных сервисах (ChatGPT, Netflix, Claude, зарубежные банки) при полной защите от блокировок местных провайдеров РФ.
- **Поддержка протоколов**:
  - **WireGuard**: классический высокоскоростной туннель с кастомными `reserved` байтами и MTU.
  - **MASQUE (HTTP/2 и HTTP/3)**: инновационный протокол проксирования поверх TLS/QUIC с маскировкой под обычный веб-трафик к CDN Cloudflare.
- **Встроенная криптография и менеджер аккаунтов**:
  - Генерация криптографических пар ключей **RFC 7748 X25519 (Curve25519)** в чистом Kotlin.
  - Регистрация бесплатных аккаунтов в актуальном Cloudflare API (`v0a4471/reg`).
  - Привязка 26-значных лицензионных ключей **WARP+ (License Key)** для безлимитного скоростного трафика.
  - Запросы к API Cloudflare автоматически направляются через защищённый туннель VPN, обходя блокировки ТСПУ в РФ.
- **Сканер чистых Anycast IP-адресов**:
  - Встроенный многопоточный сканер эндпоинтов Cloudflare с замером задержки (RTT/ping) для обхода заблокированных диапазонов провайдеров.

#### 3. Поддержка Outline Shadowsocks
- Полная поддержка ссылок `ss://` с кастомным префиксом трафика (`prefix=...`) и динамических конфигураций `ssconf://`.
- Встроенный локальный мост **OutlineBridge** (SOCKS5), защищающий исходящие сокеты через `VpnService.protect` и отправляющий префиксные байты для обхода DPI/ТСПУ.

#### 4. Поддерживаемые протоколы
- **VLESS**: поддержка транспортов TCP, WS, gRPC, режимов безопасности **Reality** и **XTLS-Vision**.
- **Hysteria 2**: современный протокол поверх UDP/QUIC с алгоритмом управления перегрузками Brutal CC и обфускацией (`obfs`).
- **WireGuard**: прямое подключение и цепочки, поддержка `reserved` байт и IPv6.
- **MASQUE**: HTTP/2 и HTTP/3 режимы проксирования Cloudflare.
- **Shadowsocks**: современные шифры `2022-blake3-aes-128-gcm`, `2022-blake3-chacha20-poly1305`, `chacha20-ietf-poly1305`, `aes-256-gcm` + Outline prefixes.
- **Trojan**, **VMess**, **TUIC**, **SOCKS5**.
- **OpenFlux**: туннелирование IPv4 TCP через Яндекс Документы и MAX Messenger при изоляции внешнего интернета.

#### 5. Маршрутизация и безопасность
- **Прямой доступ к сервисам РФ (Bypass Russian Traffic)**: домены `.ru`, `.рф`, `.su`, `.by`, `.kz`, Госуслуги, банки и маркетплейсы идут напрямую на максимальной скорости без замедления.
- **Per-App Split Tunneling**: выборочное туннелирование приложений (режимы включения/исключения).
- **Защита от утечек**: блокировка IPv6 при отсутствии поддержки, аварийный выключатель (**Kill Switch**).
- **DoH-резолвер**: встроенные пресеты Cloudflare, Google, AdGuard (блокировка рекламы), Quad9 и произвольный кастомный DoH URL.

#### 6. Интерфейс и удобство
- Интерфейс на базе **Jetpack Compose Material Design 3** с тёмной темой и плавными анимациями.
- Экран «О системе» с подробной информацией о ядре, протоколах и платформе.
- Quick Settings Tile для быстрого подключения/отключения из шторки Android.
- Экспорт детальных диагностических логов приложения и sing-box.

### 🐛 Исправления ошибок и стабильность

- **Исправлена бесконечная загрузка регистрации WARP**:
  - Устранено принудительное направление доменов `api.cloudflareclient.com` в `direct` при отсутствии активной конфигурации WARP. Теперь запросы гарантированно проходят через активный VPN.
  - Добавлены корутинные таймауты (`withTimeout(15000L)`) и уменьшены таймауты сокетов до 8 сек, исключая зависания при блокировках.
  - В интерфейс добавлена кнопка отмены и информативные карточки ошибок.
- **Исправлены циклические петли маршрутизации**:
  - Исключены сетевые дедлоки для локальных адресов моста `OutlineBridge` и сокетов `127.0.0.1`.
- **Исправлена совместимость с DNS sing-box 1.14**:
  - Устранены устаревшие строковые форматы `address` в DNS-блоке конфигурации, приводившие к сбоям резолвера.
